# Call Blocker

Call Blocker is an Android app that rejects telemarketing, spam and promotional calls before the
phone rings.

This site hosts the app's **[Privacy Policy](privacy-policy)**.

The repository behind this site also holds `spamlist.json`, the shared, community-maintained list
of spam numbers that the app downloads. The list is public so that every install can fetch it
without credentials, and so that anyone can see exactly what their phone is blocking.
